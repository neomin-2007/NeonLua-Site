# Instalação do NEON LUA

## Pré-requisitos

- Servidor Minecraft 1.8.9
- Java 8 ou superior
- Bukkit/Spigot instalado

## Passos de Instalação

1. **Baixe o arquivo .jar** da seção Releases no GitHub
2. **Coloque na pasta plugins** do seu servidor
3. **Reinicie o servidor** com o comando `restart`
4. **Configure** no arquivo `plugins/NeonLua/config.yml`

## Próximos Passos

Após a instalação bem-sucedida, configure o plugin seguindo o guia de [Configuração Inicial](02-configuracao-inicial.md).
